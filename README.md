# Homelab Platform

Automated end-to-end pipeline to provision a customized Debian 13 (Trixie) LXC container on Proxmox VE using **Terraform** and configure Docker CE with Compose plugins via **Ansible**, orchestrated seamlessly with a single **Makefile**.

Terraform provisions compute, network, and storage resources, then automatically generates the `inventory.ini` file consumed directly by Ansible.

---

## Repository Structure

```text
homelab-Platform/
├── Makefile                 # Unified workflow orchestration (make deploy, make destroy)
├── README.md

│   ├── main.tf              # LXC resource definition and auto inventory generator
│   ├── providers.tf         # bpg/proxmox and hashicorp/local providers
│   ├── variables.tf         # Input variables
│   ├── terraform.tfvars.example # Example configuration template
│   └── templates/
│       └── inventory.tftpl  # Template for Ansible inventory generation
└── ansible-proxmox/
    ├── ansible.cfg          # Ansible defaults and modern callback configuration
    ├── inventory.ini        # Auto-generated by Terraform (ignored by git)
    └── docker.yml           # Playbook to install Docker CE, Containerd, and Compose
```

## Prerequisites & Tooling Installation

Ensure you have access to a **Proxmox VE 8.x+** instance and an active SSH key pair (`~/.ssh/id_ed25519` and `~/.ssh/id_ed25519.pub`).

### Install Requirements on Control Machine

#### Arch Linux / CachyOS:
```bash
sudo pacman -S terraform ansible openssh make
```

#### Debian / Ubuntu:
```bash
sudo apt-get update && sudo apt-get install -y gnupg software-properties-common curl git python3 python3-pip pipx make

# Install Terraform via official HashiCorp repository
wget -O- [https://apt.releases.hashicorp.com/gpg](https://apt.releases.hashicorp.com/gpg) | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/hashicorp-archive-keyring.gpg] [https://apt.releases.hashicorp.com](https://apt.releases.hashicorp.com) $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list
sudo apt-get update && sudo apt-get install -y terraform

# Install Ansible Core
pipx install --include-deps ansible
pipx ensurepath
```

#### macOS (Homebrew):
```bash
brew tap hashicorp/tap
brew install hashicorp/tap/terraform ansible make
```

## Configuration

Before deploying, configure your Proxmox credentials and target LXC specifications:

1. Copy the example variable file:
   ```bash
   cp terraform-proxmox/terraform.tfvars.example terraform-proxmox/terraform.tfvars
   ```

2. Edit `terraform-proxmox/terraform.tfvars` with your settings:
   ```hcl
   # Proxmox API Connection
   proxmox_endpoint    = "[https://192.168.100.120:8006/](https://192.168.100.120:8006/)"
   proxmox_username    = "root@pam"
   proxmox_password    = "your-password-here"
   target_node         = "pve"
   ssh_public_key_path = "~/.ssh/id_ed25519.pub"

   # Container Specs & Identity
   container_id          = 101
   container_hostname    = "srv-debian"
   container_description = "Debian LXC managed by Terraform"
   unprivileged          = false

   # OS Template
   template_file_id = "local:vztmpl/debian-13-standard_13.6-1_amd64.tar.zst"

   # Compute & Storage
   cpu_cores         = 2
   memory_dedicated  = 8192
   memory_swap       = 2048
   disk_datastore_id = "local"
   disk_size         = 100

   # Networking
   ipv4_address = "192.168.100.71/24"
   ipv4_gateway = "192.168.100.1"

   # Custom Host-to-Container Bind Mounts
   mount_points = []
   ```

## Quickstart

### Automated Deployment (Recommended)

Run the entire pipeline from the root directory with a single command:

```bash
make deploy
```

This workflow executes sequentially:
1. `make infra`: Runs `terraform apply -auto-approve` to provision the LXC and generate `inventory.ini`.
2. `make ping`: Actively polls the container via SSH until the daemon is ready to accept connections.
3. `make provision`: Executes `ansible-playbook docker.yml` to install Docker CE and Compose v2.

---

### Granular Execution Targets

You can execute individual phases independently using the Makefile targets:

| Command | Description |
| :--- | :--- |
| `make infra` | Provisions or updates the container via Terraform and regenerates `inventory.ini`. |
| `make ping` | Verifies active SSH reachability against the LXC container. |
| `make provision` | Runs the Ansible Docker playbook against the provisioned host. |
| `make destroy` | Tears down the LXC container in Proxmox and cleans up resources. |
| `make help` | Displays available targets and documentation. |

---

## Manual Execution (Without Make)

If you prefer executing the steps manually:

1. **Provision Container:**
   ```bash
   cd terraform-proxmox
   terraform init
   terraform apply
   ```

2. **Configure with Ansible:**
   ```bash
   cd ../ansible-proxmox
   ansible docker_nodes -m ping
   ansible-playbook docker.yml
   ```

> **Optional non-root configuration:** To grant standard users access to the Docker daemon, pass the `docker_users` variable:
> ```bash
> ansible-playbook docker.yml -e '{"docker_users": ["admin", "developer"]}'
> ```

## Verification

Connect to the LXC container via SSH and check Docker status:

```bash
ssh -i ~/.ssh/id_ed25519 root@192.168.100.71
```

Inside the container:

```bash
docker --version
docker compose version
docker info
```

## Teardown

To stop and permanently delete the container and release Proxmox compute and storage resources:

```bash
make destroy
```

Or manually via Terraform:

```bash
cd terraform-proxmox
terraform destroy
```
